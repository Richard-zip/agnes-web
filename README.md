# 🌐 Agnes Web — Sitio Oficial y Landing Page

Sitio web oficial y portal de descargas de **Agnes**, el generador inteligente de protocolos académicos asistido por IA (Google Gemini) para la comunidad de la **Universidad de Cartagena**.

Desarrollado con [Astro](https://astro.build/) y [Tailwind CSS v4](https://tailwindcss.com/) con diseño moderno, componentes glassmorphism y optimización de rendimiento.
