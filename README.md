# 🌐 Agnes Web — Sitio Oficial y Landing Page

Sitio web oficial y portal de descargas de **Agnes**, el generador inteligente de protocolos académicos asistido por IA (Google Gemini) para la comunidad de la **Universidad de Cartagena**.

Desarrollado con [Astro](https://astro.build/) y [Tailwind CSS v4](https://tailwindcss.com/) con diseño moderno, componentes glassmorphism y optimización de rendimiento.

---

## 🚀 Características del Sitio

- 🎯 **Propuesta de Valor Clara:** Explica en pocas palabras qué es Agnes y cómo resuelve la elaboración de protocolos individuales y colaborativos (CIPA).
- 🧠 **Sección "El Garante del Aprendizaje":** Muestra el sistema interactivo de evaluación con 80% mínimo de aprobación antes de descargar el Word (.docx) o PDF (.pdf).
- 📦 **Hub de Descargas Multiplataforma:**
  - **Linux:** Enlace directo a `Agnes-1.0.0.AppImage` con instrucciones de permisos de ejecución.
  - **Windows:** Enlace a ejecutables e instaladores oficiales.
  - Enlaces directos a las releases oficiales del repositorio de GitHub: [https://github.com/Richard-zip/Agnes](https://github.com/Richard-zip/Agnes).
- ❓ **Sección de Preguntas Frecuentes (FAQ):** Preguntas interactivas sobre la clave API gratuita de Gemini, LibreOffice y requerimientos.
- ⚡ **Ultra Rápido y Accesible:** Compilación estática, Dark Mode moderno y estándares WCAG AA.

---

## 🛠️ Comandos de Desarrollo

| Comando | Acción |
| :--- | :--- |
| `pnpm install` | Instala las dependencias del proyecto |
| `pnpm dev` | Inicia el servidor de desarrollo en `http://localhost:4321` |
| `pnpm build` | Compila el sitio estático para producción en `./dist/` |
| `pnpm preview` | Previsualiza el build de producción localmente |
